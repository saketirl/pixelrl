# Humanoid Sweep Handoff - 2026-05-20

## Question

Test whether Stiefel actor/critic heads combined with AdamW and Swish improves the slippery humanoid continual-learning setup. If a config succeeds, confirm over multiple seeds and transfer to Ant.

## Code/config changes

- `ppo_brax.py`
  - Added `--base-optimizer {adam,adamw}` for Adam-managed parameters.
  - Added `--weight-decay` for AdamW-managed parameters.
  - Kept Stiefel head optimizer support separate from the base optimizer.
- `scripts/CL/brax/humanoid_sweep/sweep.sh`
  - Added `ENV_NAME` so the same launcher can run Humanoid or Ant.
  - Added `WAVE=optimizer_ablation` for Adam/ReLU, Adam/Swish, AdamW/ReLU, AdamW/Swish.
  - Added `WAVE=confirm` for multi-seed confirmation of a chosen config.

## lop-jax Slippery Ant reproduction attempt, May 23

Goal: replicate the `lop-jax/rlopt` Slippery Ant protocol in this repo before making claims about plasticity loss, then run Stiefel only if Adam shows the expected loss.

Reference protocol from `https://github.com/KevinGuo27/lop-jax/tree/main/rlopt`:

- `env=slippery_ant`
- backend effectively `positional`
- `num_envs=1`
- `total_steps=10_000_000`
- `change_every=2_000_000`
- `num_steps=2048`
- `num_minibatches=128`
- `update_epochs=10`
- `vf_coeff=1.0`
- `entropy_coeff=0.01`
- `clip_eps=0.2`
- Adam LR sweep includes `1e-4`
- Actor/critic are independent one-hidden-layer width-256 ReLU MLPs directly on observations.

New launcher:
`scripts/CL/brax/humanoid_sweep/ant_lop_protocol.sh`
